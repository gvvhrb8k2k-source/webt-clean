# قالب عرض أعمال نظيف

قالب ثلاث أقسام بهوية قابلة للتخصيص، حركة GSAP سلسة، واتجاه عربي RTL.

## التشغيل

افتح `index.html` مباشرة في المتصفح، أو شغّل خادمًا بسيطًا:

```bash
python -m http.server 4173
```

ثم افتح: `http://localhost:4173`

## استبدال الصور

استبدل روابط `picsum.photos` داخل `index.html` بالصور المحلية الخاصة بك:

- الصورة الرئيسية: `assets/hero-main.jpg`
- صورة التفاصيل: `assets/hero-detail.jpg`
- المشروع الأول: `assets/project-1.jpg`
- المشروع الثاني: `assets/project-2.jpg`
- المشروع الثالث: `assets/project-3.jpg`

يمكنك أيضًا إنشاء مجلد `assets` ووضع الصور فيه، ثم تغيير قيمة `src` إلى `./assets/اسم-الصورة.jpg`.

## تخصيص الهوية

الألوان الأساسية موجودة في أعلى ملف `style.css` عبر متغيرات `--ink` و`--paper` و`--one` و`--two` و`--three`.

للوقوف على الجانب التحسين، تم تقليل الزخارف الجانبية وإزالة القائمة المنسدلة، مع الحفاظ على تنقل واضح للجوال والكمبيوتر.
